# Night Blood

Browser-based 2D gothic urban metroidvania prototype.

## Prototype 0.1

Setting:

- New York-inspired fictional neighborhood
- 1990s gothic / underground atmosphere
- Vampire protagonist
- Melee combat
- Pixel-art presentation

## Controls

| Action | Key |
|---|---|
| Move | A / D |
| Jump | Space |
| Attack | J |
| Run | Shift |
| Restart after death | R |

## Development philosophy

All characters, environments, sprites and animations are original.

Classic gothic pixel-art games may be used as high-level references for animation weight, combat impact and atmosphere, but game assets are not copied from existing titles.
